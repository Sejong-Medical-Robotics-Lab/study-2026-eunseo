# 학습일지 - 2026-07-31 (week 2)

## 오늘 배운 것
- G1의 조이스틱 버튼 조합과 각 조작에 따른 로봇의 동작을 배웠다.
- 실기체를 사용하기 전 행어 거치, Damp 상태 확인, 기립 상태 확인 등 안전절차와 상태 전이과정을 배웠다.
- param_sweep.py를 이용하여 보행 파라미터의 안전한 범위를 확인하고, mission7_judge.py를 이용해 안정세트와 속달세트를 반복실행하여 성능을 비교하는 방법을 배웠다.

## 직접 해본 것/ 성공한 것
- G1을 직접 꺼내 행어에 거치하고, Damp 상태와 기립 완료 상태를 순서대로 확인하였다.
- 조이스틱을 직접 조작해서 G1의 기본적인 움직임을 실행하였다.
- param_sweep.py 를 이용하여 보행 파라미터를 확인하고 mission7_judge.py를 이용해 선정한 보행 파라미터세트를 반복실행하고 정상적으로 완주하는지 확인하였다.
- 직접 만든 시퀀스를 시뮬레이션으로 정상적으로 움직이는지 확인하고 실기체용 시퀀스에 옮기는 과정을 진행하였다.

## 막힌 것/ 이해가 안 되는 것
- G1로봇과 노트북 연결이 정상적으로 이루어지지 않아 관절 상태를 모니터링 하지 못해고 직접 짠  상체 모션 시퀀스를 실기체를 통해 실행해보지 못했다.

## 한 줄 소감
- 보행 파라미터 튜닝부터 직접 만든 상체 모션 시퀀스를 시뮬레이션에서 검증한 후 실기체로 옮기는 전체적인 흐름을 이해할 수 있었다. 하지만 G1로봇과 노트북이 연결되지 않아 직접 만든 시퀀스의 실기체 작동을 해보지 못해서 아쉬웠다.
